# 小程序「对话记录」与「我的」页 UI 复刻

done

## 需求

- 背景：按 Figma 复刻小程序二级页「对话记录」与 Tab 页「我的」视觉。
- 设计稿：
  - 对话记录：`node-id=325-1536`
  - 我的：`node-id=300-1152`
- 验收标准：
  1. 对话记录：淡蓝底、半透明筛选条（设备名 + 日历）、左右气泡 + 圆角方头像、时间分割样式对齐稿面；保留分页 / 日期筛选 / 音频 / 故事全文 / 家长留言能力。
  2. 我的：吉祥物位于用户卡下层（身体一部分被卡片遮住）；用户卡半透明 + 模糊；无头像时使用设计默认吉祥物头像；菜单 / 退出按钮视觉对齐稿面。
  3. 素材：单文件 ≤50KB 打进包；>50KB 走 `/static/mp/` 网络下发。
