# 管理端设备隐私可见性门禁

## 状态

done

## 需求

- 背景：对话/留言已落盘加密（见 `docs/dev/FEATURE_privacy_encryption.md`）。管理端设备管理此前可查看任意设备的对话记录、设备记忆、故事等隐私内容，与「仅调试本人设备」的预期不符。
- 验收标准：
  1. 仅当设备**绑定用户**为**当前登录管理员本人**时，管理端可打开/拉取对话记录、设备记忆、故事及相关音频。
  2. 绑定其他用户、未绑定设备：前端不展示隐私入口；后端 API 返回 403。
  3. 出厂重置 / 编辑 / MCP / 删除等运维操作不受影响。
  4. 设备列表操作栏右对齐、不透明，不再与「最后活跃时间」表头叠影。

## 设计

- 影响模块：
  - 后端：管理端对话/记忆/故事/音频接口校验 `device.user_id == 当前管理员`
  - 前端：`Devices.vue` 隐私菜单门禁（`user_id` 与本人一致）+ 操作栏样式
- API/配置变更：无新路由；既有管理端隐私读接口增加 403 语义
